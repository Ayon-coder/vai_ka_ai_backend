# Student Branch RAG Setup

The Student Branch mode uses Firestore as its semantic knowledge base:

1. `vector/manage_firebase_vectorstore.py` creates the `ieee-members` collection.
2. Each member document contains `content` and a 768-dimensional `embedding`.
3. The API embeds each new question with `gemini-embedding-001`.
4. Firestore returns the nearest member records.
5. Groq receives only the retrieved directory records and must answer from them.

## Required Environment Variables

Set these in the Render and Vercel environment dashboards. Do not commit a
service-account JSON file or a `.env` file.

```text
FIREBASE_CREDS_BASE64=<base64-encoded Firebase service-account JSON>
GOOGLE_API_KEY=<Google AI API key with Gemini embeddings enabled>
FIREBASE_COLLECTION=ieee-members
STUDENT_BRANCH_TOP_K=4
STUDENT_BRANCH_MIN_SIMILARITY=0.35
```

The existing Groq variables remain required for answer generation.

## Ingest or Update Members

Run these commands from the `vector` directory with the Firebase variables
available in that shell:

```text
python manage_firebase_vectorstore.py --upload
python manage_firebase_vectorstore.py --update
```

Use `--force` when the embedding model or embedding dimensions change:

```text
python manage_firebase_vectorstore.py --update --force
```

## Firestore Vector Index

Create a Firestore vector index for the `embedding` field with dimension `768`
and cosine distance. The exact command is generated by Google Cloud/Firebase
when the first `find_nearest` query is attempted. The backend has an exact
cosine fallback while the index is being created, which is suitable for the
small member directory but is slower for large collections.

## Privacy

The public RAG context includes names, teams, departments, college email,
LinkedIn, biographies, traits, motivation, and mottos. Personal email is not
sent to the answer model. Review Firestore security and access controls before
adding more private fields.

The Firebase credentials that were previously stored in `vector/.env` must be
rotated if they have been shared or exposed. Add the replacement values only
to deployment environment variables.
